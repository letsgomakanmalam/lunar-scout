## Eligibility rules for this project
- MUST answer the official challenge (Moon/Mars terrestrial analogs). "Create Your Own Challenge" is NOT eligible for Global Judging.
- MUST use open NASA data (plus other space agency data where possible: ESA, JAXA, CSA, ISRO, etc.) and cite every dataset.
- MUST include a Project Demo in the submission.
- MUST be submitted on the Space Apps platform before the deadline, with the terms checkbox ticked.
- Local KL judging/award times are set by the Local Lead and may differ from global times; confirm with them.
- The 2026 Project Submission Guide and Judging & Awards Guide are released 13 Nov 2026; re-check this file against them that day.

## Judging criteria (score every feature against these)
| Criterion | What judges look for | How LUNAR SCOUT wins it |
|---|---|---|
| Impact | Could this help NASA/mission planners or the public? | Ranks real + new analog sites with an explainable score; exportable site reports |
| Creativity | Original approach | Game-based "Analog Scout" missions, Twin-World View, Discovery mode |
| Validity | Scientifically sound, works, uses data correctly | Real datasets, transparent ASI formula, confidence %, cited sources, unit-tested scoring |
| Relevance | Directly answers the challenge | Identifies AND characterizes analogs; deserts, polar, volcanic, caves, impact craters; map + visualization tool |
| Presentation | Clear demo and story | 60-second playable loop, polished UI, short demo video/slides, live URL |

## Engineering rules from the rules above
- Every UI number links to a source in `sources.json`.
- Show the ASI formula in-app ("How scoring works").
- Prefer working + simple over ambitious + broken. MVP first.
- Keep a `DATA_USED.md` and `AI_USE.md` (tools used, incl. Kiro/Claude) up to date for the project page.
